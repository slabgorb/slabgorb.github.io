### Pennyfarthing

A Claude Code **agent-orchestration framework**. It coordinates a team of
specialized agents — architect, developer, reviewer, test engineer, scrum master,
and more — through structured workflows (TDD, BDD, lightweight chores), with sprint
and story management baked in. It's how a single prompt turns into planned,
reviewed, test-driven work instead of a wall of code.

[github.com/slabgorb/pennyfarthing](https://github.com/slabgorb/pennyfarthing)

### SideQuest

**An AI Dungeon Master powered by coordinated Claude agents — so everyone gets to
play.** SideQuest runs a tabletop RPG session for a whole group: the agents handle
narration, NPCs, and rules while the table just plays. It's a full product across
several repos:

- a **Python** game engine and WebSocket API
- a **React / TypeScript** client, complete with 3D dice
- a **media daemon** that generates scene art, voices NPCs with text-to-speech, and
  mixes audio on the fly
- **genre packs** — YAML-driven worlds, content, and art that let you swap settings

[github.com/slabgorb/sidequest](https://github.com/slabgorb/sidequest)
