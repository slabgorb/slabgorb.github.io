Pennyfarthing

// Claude Code agent-orchestration framework — v13+

A framework that turns a team of specialized AI agents into a single, coordinated engineering crew. I built it at 1898 & Co., then used it to build everything else I shipped there.

Active Creator & Senior Engineer 2023 — present 1898 & Co. / Burns & McDonnell
THE PROBLEM

One engineer prompting one AI assistant hits a ceiling fast. The context falls out of the window, behavior drifts between sessions, and there's no way for the work of one task to inform the next. For a critical-infrastructure consultancy with real engineering teams, that's not good enough.

I wanted something different: a crew of specialized agents that hold consistent personalities, hand work between each other along defined routes, and remember what they've done — so the whole system gets more capable over a sprint, not less.

HOW IT WORKS

Pennyfarthing is built on Claude Code and MCP. Four moving parts do the heavy lifting:

11 Agentsspecialized roles, distinct personas
Prime Contexttiered context injection
11 BikeLanesdefined handoff workflows
Framereal-time visibility
1Eleven agents, each a specialist with its own persona and remit, instead of one generalist assistant.
2The Prime Context System injects agent definition, persona, sprint state and sidecar memory in tiers — so an agent behaves the same whether it's running in the GUI or the terminal.
3Eleven BikeLane workflows and 38 slash commands define how work routes between agents, with per-agent sidecar memory so each one remembers its own history.
4Frame watches the whole thing in real time — 15 panels, browser GUI or terminal TUI.
PROVING IT WORKED

The framework's first real client was itself. By dogfooding Pennyfarthing to build Pennyfarthing, the system delivered 4,468 commits in 12 weeks — about 372 a week, or roughly 20× typical development velocity.

To make sure that velocity wasn't noise, I benchmarked agent behavior scientifically: OCEAN personality profiling, the TRAIL evaluation framework, and Cohen's d effect sizes measured across 45 persona themes.
